# Bob Sessions — IBM Bob Task Summary Screenshots

This folder contains **IBM Bob task session summary screenshots** from each team member.
These are **required for hackathon submission**.

---

## How to add your session screenshots

After completing a task with IBM Bob 2.0:

1. At the end of a Bob task session, Bob shows a **Task Summary** screen
2. Take a screenshot of that summary screen
3. Save it here with a descriptive name, e.g.:
   - `poornasri-session-01-repo-analysis.png`
   - `poornasri-session-02-bug-detection.png`
   - `poornasri-session-03-test-generation.png`

---

## Naming Convention

```
<your-name>-session-<number>-<brief-description>.png
```

Examples:
- `poornasri-session-01-architecture-mapping.png`
- `poornasri-session-02-security-audit.png`
- `poornasri-session-03-onboarding-guide.png`

---

## Requirements

- At least **one screenshot per team member**
- Screenshots must show **IBM Bob task session summaries** (the summary shown at task completion)
- Screenshots must be from **sessions related to this project**

---
